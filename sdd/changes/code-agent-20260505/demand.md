# 需求内容
现在我想设计并开发一个辅助理财的agent，这个agent的基本功能如下：
1. 能够获取中国农业银行和中国招商银行的理财产品信息，并在页面上进行展示
2. 用户会输入本金，投资的时间以及风险等级，agent需要根据理财的规则计算各个理财产品的收益，最终选择一个收益最高的理财产品

**注意事项：** 禁止直接操作用户的账户，只是做本金的计算；并且展示的理财产品需要能够在中国农业银行和中国招商银行上能够搜索到的理财产品；必须根据用户输入的风险等级进行选择，禁止无视用户输入的风险等级，最终推荐的理财产品需要符合用户对于风险等级的要求

# 功能需求
1. 能够获取这两家银行的理财产品数据，并通过前端展示界面展示这些理财产品的信息。
2. 产品的信息能够实时更新。比如第二天中国农业银行新推出了一个理财产品，则显示中也需要获取到这个理财产品的信息
3. 每个产品需要标明出处，比如产品A属于中国农业银行产品；产品B属于中国招商银行产品
4. 各个理财展品点击进入之后可以通过一个单独的界面展示产品的详细信息
5. 各个理财产品能够根据条件筛选，比如属于哪个银行，风险等级等
6. 用户需要输入本金、投资时间以及风险等级，agent需要根据判断先选出几个相对适合的理财产品，然后计算各个理财产品的收益，这些数据需要展示给用户，并给出建议，推荐用户选择收益更高，风险更低的理财产品
